# Bike Sales Dashboard in Excel

## Project Overview

This project uses Microsoft Excel to clean and analyze customer data and create an interactive dashboard exploring patterns associated with bike purchases. The dashboard allows users to filter the results and compare purchasing behavior across customer demographics.

## Dataset

The dataset contains customer demographic and lifestyle information, including age, gender, marital status, income, education, occupation, region, commute distance, and bike purchase status.

## Data Preparation

The data preparation process included:

- Preserving the original data in a separate worksheet
- Creating a working copy for cleaning and analysis
- Identifying and removing duplicate records
- Replacing abbreviated gender and marital-status values with descriptive labels
- Standardizing income formatting
- Creating age brackets with an `IFS` formula

## Analysis and Dashboard

PivotTables and PivotCharts were used to examine:

- Average income by gender and bike purchase status
- Bike purchases across customer commute distances
- Bike purchases across age brackets

The dashboard includes slicers that allow users to filter the results by customer characteristics such as marital status, region, education and occupation.
